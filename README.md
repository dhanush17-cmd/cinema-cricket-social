# Cinema Cricket Social

A social app for movie lovers and cricket fans. Users can share movie reviews, rate films, and join live cricket chat rooms.

## Features
- Movie review feed
- Rating and comments
- User profile cards
- Live cricket match chat
- Real-time messaging via Socket.IO

## Tech stack
- Frontend: React + Vite
- Backend: Node.js + Express
- Real-time: Socket.IO

## Getting started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the app:
   ```bash
   npm run dev
   ```

3. Open the browser at:
   - Frontend: http://localhost:5173
   - Backend API: http://localhost:5000

## Production build

```bash
npm run build
npm run start
```

## Project structure

- `client/` – React frontend
- `server/` – Express + Socket.IO API
